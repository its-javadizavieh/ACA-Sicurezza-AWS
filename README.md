# Sicurezza con AWS

**Sicurezza con AWS** - Complete course materials for learning and applying cloud security controls on Amazon Web Services using IAM, encryption, monitoring, network filtering, threat detection, secrets management, and backup.

## 📚 About This Repository

This repository contains hands-on labs for a 48-hour course on **AWS security**. The materials are designed for practical cloud security learning in AWS Academy Learner Lab.

Common Learner Lab permissions and cleanup rules are summarized here: [permessi_learner_lab](permessi_learner_lab.md).
